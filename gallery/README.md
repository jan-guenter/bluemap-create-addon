# Disposable Create gallery

Install the generated ZIP in the reusable disposable staging world. The load
function builds persisted-material copycat steps and panels, belt slope samples,
connected pipes with a decorative bracket, five omnidirectional casing CT cells,
frozen representative machines, and tank/vault/crafter review controls. Run
`function create_gallery:verify` for a quick presence check. A final row covers
the OBJ-backed flywheel, crushing wheel, both water-wheel sizes and blaze cage.
The footprint is
`x160..239`, `z160..215`; the suggested map center is `x199`, `z187`.
